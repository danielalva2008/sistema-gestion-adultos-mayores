# Recursos de terceros

La interfaz conserva la distribución AdminLTE entregada por el docente y sus componentes Bootstrap 5. Se añadieron copias locales de las dependencias que la propia plantilla carga desde CDN para permitir el uso sin internet.

- AdminLTE 4: https://github.com/ColorlibHQ/AdminLTE (MIT)
- Bootstrap 5.3.8: https://github.com/twbs/bootstrap (MIT)
- Bootstrap Icons 1.13.1: https://github.com/twbs/icons (MIT)
- Chart.js 4.5.1: https://github.com/chartjs/Chart.js (MIT)
- Tabulator 6.6.1: https://github.com/olifolkerd/tabulator (MIT)
- Source Sans 3: https://github.com/adobe-fonts/source-sans (OFL-1.1)

Los avisos presentes en los archivos distribuidos se conservan. Las licencias completas se incluyen en static/vendor/licencias. El driver ODBC de Microsoft se instala por separado y no se redistribuye en el ZIP.
